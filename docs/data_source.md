# Data Source Note (Stage 3)

## Primary data
- `data/raw/dataset.csv`: provided with the project brief, **never edited**. 500 rows, 7 columns (user_id, movie_title, genre, language, release_year, rating, timestamp).
- Problems found: only 8 unique titles; 309 users with about 1.6 ratings each (too sparse for collaborative filtering); every title appears with 6 genres, 4 languages and 15 release years (attributes are random per row); 27 duplicate (user, title) pairs; date-only timestamps; no movie_id.

## Extended data (SYNTHETIC)
- Generated by `src/generate_data.py` (seed 42), following the supplied Dataset Generation Prompt (extend 500 -> 5,000 rows, same columns, realistic ranges, sequential timestamps formatted YYYY-MM-DD HH:MM:SS). Generation was done with Python code written with an AI assistant (Claude); no AI-tool-produced rows were pasted manually.
- **No real MovieLens rows were used.** The structure (users x movies x ratings, long-tail popularity, user and item rating biases) is modelled on MovieLens 100K.
- Outputs in `data/raw/`: `movie_catalogue.csv`, `dataset_extended.csv`, `synthetic_taste_groups.csv`.

## What was kept from the provided file
- 473 of 500 rows (27 duplicate pairs dropped, keeping the latest rating), flagged `is_original = True`.
- Ratings and dates are unchanged; genre/language/year were re-mapped from the catalogue; a random time of day was added.
- These rows were not generated from the taste model, so they act as about 9.5% noise.

## Assumptions
1. **Catalogue:** 126 real film titles (Hindi 40, Tamil 23, Telugu 23, Kannada 12, Malayalam 9, English 19). Each has ONE fixed primary genre (one of the 6 genres in the provided data), language and year. Single primary genre is a simplification, and genre labels are my judgement. **Spot-check them before submission.** The 8 original titles are kept.
2. **Users:** the 309 user_ids of the provided file; each has 15-25 ratings (mean 16.2).
3. **Taste model:** each user is a sparse mixture of 6 latent taste groups (Bollywood mainstream, Southern action, Thriller and mystery, Hollywood sci-fi, Regional drama, Broad explorer) giving genre and language affinities, plus 4 random latent factors so matrix factorisation has structure to learn.
4. **Which films a user rates:** popularity (Zipf-like long tail, exponent 0.7) x taste fit. People rate what they chose to watch, so the average is high: the mean rating is 3.90.
5. **Rating:** 3.45 + user bias + item bias + 0.8 x taste affinity + latent interaction + Gaussian noise (sd 0.6), rounded to 0.5 and clipped to 1-5.
6. **Timestamps:** within 2024-01-01 to 2025-12-31, never before a film's release year (2024 releases not before 2024-09-01); file sorted ascending.
7. `synthetic_taste_groups.csv` is generator ground truth used ONLY in the Stage-10 fairness/diversity audit. It is **never a model input**.

## Deviation from the generation prompt
The prompt says to use the exact same columns as dataset.csv. The first 7 columns are identical in name and order; I appended `movie_id` (the brief lists it, and it removes title ambiguity) and `is_original` (traceability).

## Ethics
No demographic attributes, names, or personal data. All ratings beyond the provided rows are synthetic and do not describe real people. Results come from synthetic data and may not transfer to real audiences (stated as a limitation).
