# AI-tool usage disclosure (for the report appendix and the declaration)

**[Learner: read this, make sure it is accurate for your own work, and check the programme's rules on AI assistance before submitting.]**

An AI assistant (Claude, developed by Anthropic) was used throughout this project in a guided, stage-by-stage conversation that followed the programme's Industry Project Build Guide.

**What the assistant did:** wrote the Python code for data generation, cleaning, splitting, the baselines, user-based CF, item-based CF, SVD wrapper, tuning, evaluation, the diversity and fairness audit, the Flask API, the Streamlit dashboard and the 56 automated tests; produced the EDA notebook, the architecture diagrams, the report and synopsis drafts and the documentation; ran the code and reported the outputs. Every number in the report was produced by that code and read from saved result files.

**What the learner did:** supplied the project brief, dataset and templates; directed the stages; and remains responsible for reviewing, running and understanding every part of the work, checking the film genre labels in the generated catalogue, capturing the screenshots, recording the demo, and completing and signing the declaration.

**Data:** the ratings beyond the 473 rows of the provided file are synthetic, generated by a script written with the assistant (src/generate_data.py, seed 42). No rating rows were pasted from an AI chat, and no real personal data was entered into any AI tool.

**Mistakes by the assistant that were caught and fixed:** a flawed item-CF formula (found by a sanity check), a NaN bug at zero shrinkage, an unverified explanation of a data pattern (checked and corrected), and several report-generation bugs. They are described in the report.
